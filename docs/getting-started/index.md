Follow the shortest path to a working render, then branch into the guide that matches
your input and output model.

-   :material-download:{ .lg .middle } **1. Install**

    ---

    [:octicons-arrow-right-24: Installation](installation.md)

-   :material-image-check:{ .lg .middle } **2. Render**

    ---

    Generate a deterministic PNG from HTML and an explicit stylesheet.

    [:octicons-arrow-right-24: Quickstart](quickstart.md)

-   :material-sign-direction:{ .lg .middle } **3. Go deeper**

    ---

    Select the rendering, resource, template, or animation guide for your workload.

    [:octicons-arrow-right-24: Browse guides](../guides/index.md)

</div>

!!! tip "Using custom text or images?"

    Read [Fonts and images](../guides/resources.md) immediately after the quickstart
    when you need non-Latin text, brand fonts, or in-memory images. The bundled Geist
    face is a Latin last-resort font, not a general-purpose font collection.
