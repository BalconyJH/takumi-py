# 快速入门

沿最短路径完成一次渲染，再进入与你的输入和输出模型相匹配的指南。

<div class="grid cards" markdown>

-   :material-download:{ .lg .middle } **1. 安装**

    ---

    使用已发布的 wheel，或准备包含 Takumi 子模块的源码检出。

    [:octicons-arrow-right-24: 安装](installation.md)

-   :material-image-check:{ .lg .middle } **2. 渲染**

    ---

    用 HTML 和显式样式表生成确定性的 PNG。

    [:octicons-arrow-right-24: 快速上手](quickstart.md)

-   :material-sign-direction:{ .lg .middle } **3. 深入**

    ---

    为你的工作负载选择渲染、资源、模板或动画指南。

    [:octicons-arrow-right-24: 浏览指南](../guides/index.md)

</div>

!!! tip "需要自定义文字或图片？"

    需要非拉丁文字、品牌字体或内存中的图片时，请在快速上手之后立即阅读
    [字体与图片](../guides/resources.md)。内置的 Geist 字体只是拉丁文字的最后回退，
    并不是通用字体集。
