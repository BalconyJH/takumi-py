# 迁移

迁移指南描述 Takumi 核心版本之间的行为变化和必需的代码改动，不重复变更日志中逐个提交的
记录。

<div class="grid cards" markdown>

-   :material-numeric-2-box:{ .lg .middle } **Takumi v2**

    资源归属、HTML 解析、字体描述符、语言行为和输出方面的变化。

    [:octicons-arrow-right-24: 打开迁移指南](takumi-v2.md)

-   :material-update:{ .lg .middle } **Takumi 2.17**

    按 `unicode_range` 划分的字体子集、弃用的 `subset_of` 与 Floyd–Steinberg 抖动、
    动画帧率上限，以及与 Chrome 对齐的渲染。

    [:octicons-arrow-right-24: 打开迁移指南](takumi-2.17.md)

</div>
