Nodes and result types¶

The Python type layer defines node inputs, measurement results, and animation scenes.

AnimationScene.duration_ms and RawAnimationFrame.duration_ms must be positive. Raw animation frames also require positive dimensions and exactly width * height * 4 RGBA bytes.

RawRgbaImage describes decoded row-major RGBA pixels used as an ImageNode.src. Its byte length follows the same width * height * 4 contract.
